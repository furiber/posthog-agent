Analytics Audit Agent — architecture

One run: crawl a website's analytics instrumentation, validate it adversarially, ship a five-section markdown report over SSE.

Agent framework: Cloudflare Agents SDK — agents npm pkg (agent lives in a Durable Object) Model access: OpenRouter — OpenAI-compatible endpoint Browser: Cloudflare Browser Rendering — @cloudflare/playwright Grader: TypeSafe Jev — systemone choice grader Config: cloudflare.config.ts (cf CLI)

AnalyticsAuditAgent — Durable Object (Cloudflare Agents SDK)

All four roles share this one agent state — evidence IDs survive every handoff. The adversarial reviewer's fresh context is the sole exception (a fresh model call, never a separate agent session).

① Crawler — tool-stepping loop

Agents SDK streamText + tools → z-ai/glm-5.3-flash via OpenRouter (reasoning pinned low)
  • Tools: sitemap_discover(url, pageBudget)load_page(url)inspect_dom()interact(selector|preset)record_evidence(...)finish_crawl(reason)
  • load_page injects request interception: beacons on the wire (PostHog /e/, /i/v0/e/, /batch, /decide · GA4 collect?v=2 en= · GTM gtm.js · gtag.js)
  • interact fires scripted interactions: CTA click · consent toggle · honeypot-ignored form submit
  • Tool retries: 4 (8 for pages that fail to render / SPA-complex) · 40 successful steps per page
  • May run several browser contexts in parallel — tool-level concurrency, never separate agent sessions

② Synthesizer

z-ai/glm-5.3-flash via OpenRouter (one small JSON call)
  • Events/tags/gaps tables assembled deterministically from evidence
  • Naming convention derived from the wire (default: object_action snake_case; GA4 terminology-locked)
  • Single validated model step: the tracking plan (server-checked evidence IDs + convention)

③ Adversarial reviewer

deepseek/deepseek-v4.1-flash via OpenRouter — fresh context
  • Critique-only prompt; verifies every claim against cited evidence
  • Hunts: hallucinated events · missed events · misclassified dest/interaction · convention violations · wrong recommendations
  • Outputs structured critique items (≤12, each citing evidence IDs)

④ Jev adjudicator

TypeSafe systemone API — api.typesafe.ai/v1/systemone · model jev-latest
  • Grades each critique: Correct Partially Correct Incorrect
  • Only Jev-Correct critiques propagate; <0.7 confidence flagged for human review
  • Structured claim+evidence state in, strictly structured JSON out — never one of the report-writing models

Evidence store — append-only, Durable Object SQLite

Every beacon / snippet / DOM observation gets an ID (E000001…): {site, pageUrl, timestamp, kind: beacon|snippet|dom, payload, interactionStepId?}. No claim may exist without an evidence ID — enforced again at the final gate.

"Are you using v0?" No. Nothing in this build is v0-generated. The locked stack: Cloudflare Agents SDK (agents npm package — the agent is a Durable Object, the SDK runs the crawler's tool-stepping loop) for the agent framework, OpenRouter for all chat model access (OpenAI-compatible endpoint, flash-tier GLM 5.3 Flash + DeepSeek 4.1 flash), Cloudflare Browser Rendering for browsing, and the TypeSafe Jev systemone API as the separate grader call site. No second agent framework was introduced.
